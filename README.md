# CDUResources

Canonical editable resource-pack assets and artist tooling for CDU's Quasar GUI redesign.

**Status: implemented design; client validation pending.** All 54 audited skins and six chest templates use dark framing. Thirty-one have painted control regions; seven paged layouts use 28 native content cells. Storage, selectors, configured shops and crafting preserve protected native positions. See docs/DESIGN-COVERAGE.md for every skin. Static validation does not prove gameplay or client rendering.

Edit background, button-state and decorative PNGs in `pack-source/assets/quasar_gui/textures/`. Normal builds preserve those source images and optional Aseprite documents. Geometry, fonts and audited control meaning are in `manifests/`; the implemented interaction contract is `manifests/button-layouts.json`. This repository contains no Quasar gameplay source or compiled mods.

## Start on Windows

Download this repository as a ZIP and extract it, or clone it. The ready-to-open browser tools are included at the repository root:

- [CONTROL-EXPLORER.html](CONTROL-EXPLORER.html): inspect every menu, visible artwork, slot targets and existing actions.
- [LAYOUT-EDITOR.html](LAYOUT-EDITOR.html): position existing clickable controls and supported item displays, preview states and export layout changes.

Double-click either HTML file to open it locally in your browser; no Python setup is needed for these included copies. GitHub displays their source instead of running them. Both work offline. Full guide images and illustration sheets are generated by **Build Pack.cmd** and included in the downloadable artist kit.

Install Python 3.12 once, then double-click **Setup Artist Tools.cmd**. Paint the supplied PNGs in Aseprite, and double-click **Build Pack.cmd** to export, validate and package your work. Optional Aseprite source documents stay in `artwork/`; PNG-only editing also works. Read [the Aseprite workflow](docs/ARTIST-WORKFLOW.md) for indexed frame exports, local Minecraft preview and committing source changes. **Open Layout Helper.cmd** is an optional alignment aid.

## Build and verify

Use Python **3.12** locally (CI pins **3.12.14** in `.python-version`), and the pinned Pillow dependency:

```sh
python -m pip install -r requirements.txt
python tools/check_artifacts.py
```

The check command builds the resource pack, runs 23 pack tests, 15 artist-tool tests and (when Node is installed) 20 layout-model regression groups, verifies byte-identical repeated pack and artist-kit builds, and extracts the artist kit into a fresh directory. It rebuilds and tests that portable copy, then checks that a texture override appears in its exported PNG and offline guide while the canonical source remains unchanged. The suite covers real button regions, state glyphs, content masks, carrier model ranges and hash-bound layout sidecars.

Outputs are generated under `deliverables/`: `quasar-gui.zip`, its hash-bound `quasar-gui-layouts-<sha1>.json`, `quasar-gui-artist-kit.zip`, their checksum files, and `checksums.json`. Evidence is under `evidence/`. Generated output directories are ignored by Git. The same ZIP currently targets Minecraft Java 1.19.2, 1.20.1 and 1.21.1; read [client compatibility](CLIENT-COMPATIBILITY.md) for format warnings and verification limits.

For an ordinary rebuild, run `python tools/build_pack.py`. Builds refresh both committed HTML tools from the current artwork and manifests. Commit those refreshed files with your art/layout changes; CI rejects stale browser tools. Start with [the artist guide](START-HERE.md) and [texture overrides](docs/ARTIST-OVERRIDES.md). Use `--regenerate-samples` only when intentionally replacing canonical PNGs with procedural defaults.

For Minecraft **26.1.2**, `python tools/build_pack_26.py` derives a separate format-84 release from the exact validated cozy ZIP. It preserves every artwork/font byte, removes the obsolete vanilla paper override, and adds the `quasar_gui:button_carrier` empty item model. It emits a new SHA-bound layout sidecar under `deliverables/26.1.2/`; it never replaces the older release. The Quasar 26 integration must use `minecraft:item_model` and this new hash. `tools/Check26Pack.java` verifies metadata, all 1,053 font providers and the carrier with the official released 26.1.2 client codecs on Java 25. Client rendering is a separate deployment check. Minecraft 1.12 is excluded; no backport is provided.

## GitHub Actions

[Resource pack checks](.github/workflows/resource-pack.yml) runs on pushes to `main`, pull requests targeting `main`, and manual dispatch. It uses pinned Python/Pillow versions and commit-pinned official GitHub actions. Successful runs attach pack, artist-kit and checksum artifacts; verification evidence is attached even after a failed check. Artifacts follow the private repository's access rules and expire after 30 days. The workflow needs only `contents: read` and GitHub's automatic token; it creates no release, public host or deployment.

Changes are committed directly to `main` according to the repository owner's workflow. [CI provenance](docs/CI.md) records action versions and their official sources.
