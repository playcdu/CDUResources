Artwork stays editable

PNG exports contain artwork only. Masks and slot numbers are never painted into them. Resizing a hit region requires six matching-size state PNGs or explicit regeneration in the builder.

Save your layout

A project stores layouts plus imported PNGs. It is a helper document, not a Minecraft pack. Export changed PNGs to the paths above and put the layout JSON in manifests/button-layouts.json.

Local artist loop
  1. Edit PNGs or registered Aseprite sources.
  2. Run Build Pack.cmd. Validation checks geometry, masks and frame dimensions.
  3. Use artist.py install-preview --minecraft <instance> for your own profile.
  4. Enable the preview pack once; press F3+T, then /invdebug quasar reload.
  5. Commit sources, exports, receipts and layouts to main. Actions builds the handoff artifacts.

Player inventory and native content stay protected. Decorative frames may extend beyond the window; click regions cannot. This helper does not add new gameplay bindings.
