    Artist replacement

    1 · Bitmap artwork

    Backgrounds and independent normal, selected, disabled and pulse frames paint the controls. State frames are separate glyphs.

    2 · Items and carriers

    Real content stays visible through clear wells. Painted controls use invisible nonempty carriers that retain native names and tooltips.

    3 · Original action

    Each cell of a wide button dispatches the same original logical action, with its existing permissions, prices and transaction checks.

    Try the guided demo in Minecraft: enable the pack, then use /invdebug quasar demo economy themed. Omitting the mode uses standard menus. The preview uses synthetic values and actions. Its tooltips explain what each real Quasar control does. Use /invdebug quasar help for more flows.

    This guide uses original schematic item tokens and the actual pack artwork. No Minecraft assets are embedded. Artwork and slot geometry are measured in logical GUI pixels.
